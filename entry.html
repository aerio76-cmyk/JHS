資料備份

下載備份

把學生、段考成績與校排名下載到這台電腦。建議每次輸入完一批成績後下載一次，至少每學期一次；檔案請存到雲端硬碟或隨身碟等第二個地方。

「完整備份」可以用來還原；CSV 可以直接用 Excel 開啟查看。頭像照片不在備份裡：還原到原本的資料庫時頭像維持原狀，還原到新的資料庫時會顯示預設頭像。

檔案含學生英文名與成績，請存在私人的位置，不要上傳到公開的地方。下載時請不要同時在其他裝置輸入成績。

從備份產生還原 SQL

選一個「完整備份（JSON）」檔，網站會產生一份還原用的 SQL 檔，不會直接改動資料庫。

  1. 選擇備份檔，下載產生的 .sql 檔。
  2. 到 Supabase Dashboard → SQL Editor，貼上整份內容後按 Run。
  3. 最後一行會列出學生、成績、排名的筆數，應該跟備份一致。

還原會新增或覆蓋同一位學生、同一次段考的資料，不會刪除備份裡沒有的資料。只用自己從這裡下載的備份檔，不要用別人傳來的檔案；建議先在測試用的 Supabase 專案試跑。
