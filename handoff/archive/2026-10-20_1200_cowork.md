## 2. 任務 A｜家長端「匯出資料」
**範圍**：只新增前端匯出，不新增資料表、不新增後端、不引入打包或壓縮函式庫。

**位置與權限**：`entry.html` 新增「資料備份」區塊（用現有 hash 切換風格）。登入且在白名單內才看得到；未登入與無權限畫面不顯示。

**匯出內容**：`students`、`exam_scores`、`exam_rankings` 三張表。（小語在 `seed_data.sql`、白名單在本機 `rebuild.local.sql`，不匯出；頭像圖檔在 Storage，不在備份內，還原後以預設頭像或重新上傳處理，請在畫面說明一句。）

**格式（三個按鈕，各下載一個檔，避免多檔連續下載被瀏覽器擋）**
1. **完整備份（JSON）**：`jhs-backup-YYYYMMDD-HHMM.json`。含 `exportedAt`、`format`（版本字串，例如 `jhs-backup-1`）與三張表的完整列。**不得包含 anon key、專案網址或任何憑證。**
2. **成績（CSV）**：長表格式，欄位建議：英文名、年級、學期、段考、科目、分數、考試日期。UTF-8 **含 BOM**，讓 Excel 正確開啟中文。
3. **校排名（CSV）**：英文名、年級、學期、段考、名次、總人數。

**實作要求**
- 讀取一律分頁（`range` 迴圈），不依賴單次 1000 列上限，即使現在最多約 180 列。
- 所有輸出文字用 `textContent`；CSV 儲存格若以 `= + - @` 開頭要加前綴防公式注入；欄位含逗號、換行、雙引號要正確跳脫。
- 以 Blob + `<a download>` 下載，下載後 `revokeObjectURL`；**確認現有 CSP 不需要放寬**（若需要，停下回報，不要自行放寬）。
- 0 筆資料時仍要輸出合法檔案（CSV 只有標題列；JSON 空陣列），不報錯。
- 畫面顯示「上次在這台裝置匯出的時間」：用 `localStorage`，所有讀寫包 try/catch，讀不到就不顯示。只是提示，不做彈窗、不催促。
- 成功與失敗訊息走現有常駐 live region；匯出期間按鈕鎖住，防重複點擊。

**還原路徑（這項是備份有沒有用的關鍵，請務必驗證）**
- 新增純函式（建議放 `js/backupLogic.js`，含 Node export）：JSON → 可在 Supabase SQL Editor 執行的 `INSERT … ON CONFLICT` 語句；CSV 序列化也放這裡。
- 還原只支援**寫成 SQL 檔由使用者手動執行**，不做網站上的還原按鈕。
- README 補一節「備份與還原」：多久匯出一次（建議每次輸入完一批成績後，或至少每學期一次）、檔案存哪裡、怎麼還原、頭像不在備份內。
- 驗證：用 PGlite 做**來回測試**：以假資料匯出 → 在空資料庫套用 `schema.sql` → 執行產生的還原 SQL → 逐表比對列數與每個欄位值一致（含學生主題色、`avatar_url` 為 null 與非 null、考試日期為 null、分數 0.5 單位）。

**驗收標準**
1. 非白名單與未登入看不到此區塊。
2. 三個檔案都能下載；CSV 在 Excel 開啟中文不亂碼（至少用 BOM 與編碼檢查驗證，無法開 Excel 就明說）。
3. 來回測試通過（見上）。
4. 360 px 無橫向溢出、無 console error、無 CSP 錯誤。
5. `npm test` 持續全綠並新增測試：CSV 跳脫、公式注入、空資料、特殊字元、分頁邊界（剛好 1000 列、1001 列的模擬）。

**角色**：implementer → test-writer → reviewer → fixer → **data-validator**（用在還原來回比對；呼叫時附手算樣本）→ security-auditor（輕量，範圍：CSV 注入、Blob 下載與 CSP、檔案內容不含憑證、`localStorage` 使用）。

- `index.html`、`entry.html` 加 `<meta name="robots" content="noindex, nofollow">`；確認 CSP 不受影響。
