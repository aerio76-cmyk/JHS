### 5.4 Google OAuth 需要核對的項目
`auth.js` 的 `redirectTo` 是「目前頁面的網址去掉 hash」，所以 Supabase 的 Redirect URLs **必須包含實際使用的網址**。需要使用者提供畫面或自行確認：
1. **Supabase → Authentication → URL Configuration**
   - Site URL：建議 `https://aerio76-cmyk.github.io/JHS/`
   - Redirect URLs 要包含 `https://aerio76-cmyk.github.io/JHS/entry.html`。如果要在本機測試，另加 `http://127.0.0.1:8765/entry.html`。
2. **Google Cloud Console → APIs & Services → Credentials → OAuth 2.0 Client**
   - Authorized redirect URIs 要包含 `https://cfalawxigobkpqjtcpzq.supabase.co/auth/v1/callback`。
3. **Google Cloud → OAuth consent screen**：如果 Publishing status 是「Testing」，家長的 Google 帳號必須在 Test users 名單內。
4. **Supabase → Authentication → Users**：家長的 Google 帳號已經在名單上，而且 email 和 `admins` 白名單一致（白名單 email 只寫在本機 `rebuild.local.sql`，不進版控）。重建資料庫時沒有動到 `auth.users`，如果以前登入過，應該還在。
